# Solidity Study

This is my personal repository for practicing Solidity and learning blockchain development.

## 🔧 What I’ve practiced so far

### ✅ HelloWorld.sol
- My first smart contract written in Solidity.
- It stores a message and allows the user to change it.
- Functions:
  - `message()` – returns the current message
  - `setMessage()` – updates the message

## 🛠 Tools Used
- Remix IDE (https://remix.ethereum.org)
- Solidity 0.8.x

## 📚 What I Learned
- Basic smart contract structure
- How to use variables and functions in Solidity
- How to deploy and test contracts in Remix
